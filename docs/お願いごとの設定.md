# お願いごとの設定

びくたんに「決まった仕事」を頼めるようにする設定です。

```
あなた: Inbox整理しておいて
びくたん: Inboxの整理ですね。やってしまっていいですか？   ［お願い］［やめておく］
あなた: （お願いを押す）
びくたん: Inboxの整理、やっておきました。（3件を移動しました）
```

**設定していない人には、この機能は現れません。** 自分で置いた時だけ動きます。

## 置き方

トレイメニュー →「🗂 データ管理」→「🧹 お願いごとを設定する…」を選ぶと、
雛形が入り、**`errands.json` を選んだ状態**でフォルダが開きます。

```
<設定フォルダ>/
├── errands.json    … 何を頼めるかの定義（これを書き換える）
└── errands/        … 実行するものの置き場所
```

**`errands.json` は `errands` フォルダの中ではなく、ひとつ上にあります。**

設定フォルダはここです。

- macOS: `~/Library/Application Support/bikunavi-desktop/`
- Windows: `%APPDATA%\bikunavi-desktop\`

## errands.json の書き方

```json
[
  {
    "label": "Inboxの整理",
    "script": "organize-inbox.sh",
    "keywords": ["inbox", "インボックス", "受信箱"],
    "verbs": ["整理", "片付", "仕分"]
  }
]
```

| 項目 | 意味 |
|---|---|
| `label` | 確認する時に読み上げる名前。「〇〇ですね。やってしまっていいですか？」 |
| `script` | `errands/` の中の**ファイル名だけ**。パスは書けません |
| `keywords` | このどれかが言葉に含まれた時だけ反応します |
| `verbs` | 省略できます。省略すると 整理・片付・仕分・作る・用意・実行 を見ます |

`_memo` のように知らない項目を書いても無視されるので、メモとして使えます。

## 動く条件

**うっかり実行しないよう、三重に絞っています。**

1. **対象と動作の両方**が要る。「整理しておいて」だけでは動きません（部屋の片付けとも取れるため）
2. **頼む形**が要る。「Inboxが散らかってる」では動きません
3. **確認に答える**必要がある。曖昧な返事（「ところで今日は何日？」など）では実行せず、普通の会話に戻ります

質問は依頼として扱いません。「Inbox整理した？」で動くことはありません。

## 実行できる範囲

**`errands/` フォルダの中に置いたものだけ**です。

`script` にパス区切りや `..` を含むもの、絶対パス（`/bin/sh` など）は、
読み込む時点で捨てます。設定ファイル1つでどこの何でも動かせる箱にしないためです。

別の場所にあるものを頼みたい時は、`errands/` の中へコピーするか、
シンボリックリンクを張ってください。

```bash
ln -s ~/Documents/Brain/03_AI/Mac内操作/scripts/organize-new-incoming.sh \
  ~/Library/Application\ Support/bikunavi-desktop/errands/organize-inbox.sh
```

## 報告のされ方

実行した後、**出力の最後の3行**が報告として読み上げられます。長い出力は
そのままでは読み上げに向かないので、伝えたいことはスクリプトの最後で
`echo` してください。

止まったままにならないよう、**120秒で打ち切ります。**

### 後から確かめる

吹き出しは時間で消えるので、**動いたかどうかを見に行ける場所**があります。

```
<設定フォルダ>/errands/実行の記録.txt
```

いつ・何を・終了コードいくつで終わったか、出力ごと残ります。大きくなったら
古い方から落とすので、放っておいて構いません。設定フォルダを消せば一緒に消えます。

**スクリプト側にも証拠を残すのがおすすめです。** 同梱のサンプルは、実行するたびに
`errands/サンプルの実行あと.txt` へ日時を書き足します。ファイルを作る・書き換える
仕事なら、その結果そのものが証拠になります。

## 気をつけること

- **取り消せない仕事は慎重に。** 確認は挟みますが、押し間違いは起こり得ます。
  ファイルを消す・上書きするものは、それ自体にバックアップを持たせてください
- **AIの出力からは自動生成しません。** 人が自分で書いたものだけを読むので、
  会話の流れで勝手に仕事が増えることはありません
- 一度に登録できるのは12件までです
