声で話しかけられるようになり、じゃまな時はそっと引くようになったアップデートです。

## 変わったこと

### 声で話しかけられます（試験中）

- 会話欄のマイクを長押しすると「ハンズフリー会話」が始まります。以後はキーボードもクリックも使わず、声をかけるだけで聞き取ります
- 読み上げの途中でも、答えを考えている途中でも割り込めます。話しかけた時点でびくたんは黙り、そちらを聞きます
- 聞き取りはmacOSの音声認識を優先します。うまく聞き取れなかった時は勝手に解釈せず、「〜で合ってますか？」と一度だけ確かめます
- まわりの物音を言葉と取り違えた時は、返事をせずに黙ってやり過ごします

### じゃまにならないようにしました

- **びくたん以外へクリックを通す**: びくたん本体と吹き出し以外の透明な部分で、後ろのウィンドウをそのまま操作できます。最前面に居たまま、作業のじゃまだけがなくなります
- **待機中はうすく表示**: しばらく話しかけられないと、うとうとして眠るように薄くなります。話しかければ起きて元に戻ります
- どちらもメニューバー →「🖥 表示・サイズ」から切り替えられます（初期値OFF）

### 返事がしやすくなりました

- びくたんが「〜ですよね？」と問いかけた時、吹き出しに選択肢ボタンが出ます。キーボードを使わずワンクリックで返せます
- ニュースや情報に「👍 / 👎」を付けられるようになりました。👍を付けた分野は次から多めに、👎を付けた話題は減らして集めます
- 👍を付けた記事は、これまでどおりメニューバーの「気になる記事」から見返せます

### 話が続くようになりました

- ひとつの話題を2〜4行かけて話すようになりました。吹き出しを消さずに続けるので、ひと続きの話として読めます
- 教わった言葉を2つ組み合わせて話すことがあります
- 会話AIに繋いでいなくても、時間帯・音楽・ポモドーロに合わせたセリフを話します

### 音楽

- 朝・昼・夜に一度ずつ、作業に合うBGMを薦めます（YouTube検索リンク付き）
- 好きな音楽のジャンルを教えておくと、そのジャンルのアーティストも一組添えます
- ポモドーロを始める時にも、集中に合うBGMを一緒に渡します
- しばらくぶりに起動した時は「おかえりなさい」と一緒にBGMを薦めます

### 仕草

- 掴んで動かすと、慣性で体が振られて傾きます。手を離しても揺り戻しながら収まります
- 触れている間、ときどき口角を上げて口を開きます
- 夜が更けるほど、そして放っておかれるほど、うとうとしてきます

### メニューを整理しました

- 「びくたんと育つ」を「何か聞いてもらう」ひとつにまとめました。何を教えるかはびくたんが選びます
- 「ふたりの記録」まわりの言葉づかいを、びくたんの言い方へ揃えました

### 直したこと

- 深夜に用意したセリフを朝に話してしまう問題を直しました
- 何時間も前のセリフを「いま返事をした相手」と取り違えて、話が噛み合わなくなる問題を直しました
- 表示をオフにしても、しばらくすると勝手に出てくる問題を直しました
- まわりが騒がしいと声を拾えなくなる問題を直しました
- デザインの話題に、サッカーやグッズなど無関係な記事が混ざる問題を直しました
- びくたんが「今日の予定を整えています」のように、実際にはしていないことを言う問題を直しました
- ホバー中に口が動いて、話していないのに喋って見える問題を直しました
- 吹き出しが出ている間だけ、後ろのウィンドウを触れなくなる問題を直しました
- 内部の印（`cont|` など）がセリフに混ざって表示される問題を直しました
- びくたんが実際にはしていないことを「しています」と言う問題を直しました

## インストール

1. 下のZIPをダウンロードして展開
2. `びくたん.app` を「アプリケーション」フォルダへ移動（上書きでOK。設定・育成データは引き継がれます）
3. 公証未対応のため、初回は「システム設定」→「プライバシーとセキュリティ」→「このまま開く」を選んでください

「壊れているため開けません」と表示される場合に限り、Release記載のSHA-256を確認してから次を実行してください:

```bash
xattr -cr /Applications/びくたん.app
```

ダウンロードしたZIPのSHA-256:

```text
2bb60c9e970b2a0090e45a830365ad5d9051aee06ed39f2b6e87fa4c4a159beb
```

## 音声入力について

ハンズフリー会話とマイク入力では、macOSの音声認識（Apple Speech）を優先して使います。端末内認識に対応した機種では端末内だけで処理しますが、対応していない環境ではmacOSがAppleのサーバーへ音声を送ることがあります。端末内で完結させたい場合は、同梱のWhisperだけを使う設定にできます（環境変数 `BIKUNAVI_STT_ENGINE=whisper`）。

録音した音声ファイルは、文字起こしの成否にかかわらず処理後に削除します。
